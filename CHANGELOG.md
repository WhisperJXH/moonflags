# Changelog

## 0.2.1 - 2026-08-17

- Finalized project proposal wording for completed acceptance materials.
- Clarified final verification evidence and package publication status.

## 0.2.0 - 2026-08-17

- Added a reusable preset catalog with 175 typed Rule / Flag / Context recipes.
- Added catalog tests covering preset lookup, evaluation and validation.
- Clarified ecosystem positioning, project boundaries and source scale.

## 0.1.0 - 2026-08-15

- Added MoonBit-native feature flag data model.
- Added context attributes for strings, integers, booleans, and string lists.
- Added condition helpers for equality, existence, containment, prefixes, suffixes, and integer comparison.
- Added named segments with include/exclude users and reusable conditions.
- Added deterministic rollout bucket selection with basis-point weights.
- Added flag and flag-set evaluation APIs.
- Added configuration validation diagnostics.
- Added runnable example, README, project proposal, design notes, tests, and CI workflow.
